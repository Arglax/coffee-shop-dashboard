# Cafe Dashboard

A private, client-side sales dashboard for a cafe. Load a POS sales export (CSV) and get KPIs, insights, a profit-and-loss view, cash flow, per-item comparisons and a small forecasting model. Everything runs in the browser; the CSV never leaves the device (the last file is remembered in `localStorage`).

## Features

- **Dashboard**: KPIs, rule-based insights with recommended actions (editable thresholds), top days/hours/items, trends
- **Numbers**: time series, hour × weekday heatmap, P&L with your own monthly costs, cash flow by payment type, category table, daily ledger
- **Items**: compare up to 3 items or sizes, daily/hourly/weekday charts, "often bought with", item photos with fallback
- **Forecast model**: ridge regression on daily totals with editable parameters and a 7-day forecast
